## 💻 Development environment

### Requirements

- Docker installed with daemon running (choose one option):

  - Docker Desktop (easy to install but heavy and consumes a lot of RAM)
  - Orbstack (good compromise between performance and UX/DX)
  - Colima (best performances but without UI - all commands provide via CLI)

- .env.development
- .env.integration (for dump)

All .env files are available in Dashlane (strapi.env.\*)

### Copy integration data to local database

```bash
node ./scripts/node/dump-remote-database.mjs --source integration
node ./scripts/node/development/write-dump-into-local-database.mjs --source integration
```

### Start development environment

```bash
npm run dev # or npm run dev:build if necessary (new Strapi version for example)
```

### Internationalization

> Settings > Internationalization > Add new locale

Locales : French (fr) > Default locale : French (fr)

### API Token

> Settings > API Token > Create new API token

Name : `string`

Token duration : Unlimited

Token type : Read-only

### Webhooks

> Settings > Webhooks > Create new webhook

Name : `Nextjs revalidate` for example

URL : `<NEXT_JS_URL>/api/revalidate`

Headers : `Key : Authorization` | `Value = <secret_next_js_token>`

Events : `Entry` (check all)

### Configure views

Each user can have a different view of the application

### 🔀 Services and API

---

#### ‍💻 Bitbucket Service Account

Bitbucket's pipelines are used to deploy the Strapi Node.js project on GCP Cloud Run.

> `bitbucket@<project_id>.iam.gserviceaccount.com` - Bitbucket

🗒️ Please check if Bitbucket service account has the following roles :

- Cloud Build Service Account (Compte de service Cloud Build)
- Service Account User (Utilisateur de compte de service)
- Cloud Run Developer (Développeur Cloud Run)
- Artifact Registry Writer (Rédacteur Artifact Registry)

> 💡 You may need to activate the service account with GCLoud CLI : https://cloud.google.com/sdk/gcloud/reference/auth/activate-service-account

```bash
gcloud auth activate-service-account <service@account>.iam.gserviceaccount.com --key-file <key_file>.json
```
